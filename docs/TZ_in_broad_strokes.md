# В общих чертах

По правилам 6928.pdf. Общий словарь, 25 прозрачных планшетов, две попытки после каждого слоя. Только чёрные штрихи. При расхождении формы слова художник может засчитать ответ. Сдачу подтверждает хост после общего решения.

Первый лист по центру. На следующих ходах предыдущие слои сдвигаются влево и уменьшаются до 80%, новый лист по центру. При совмещении старые слои увеличиваются, новый лист переезжает влево.
