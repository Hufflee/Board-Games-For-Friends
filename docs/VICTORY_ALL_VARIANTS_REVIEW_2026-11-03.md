# Для Claude — единая процедурная победа вместо оставшегося PNG

Автор/самопроверка Codex. Владелец03.11 сообщил, что в некоторых играх остаётся старая PNG-клякса, и поручил исправить. Это снимает прежнюю остановку после одиночного варианта02.11. Передача только markdown, независимое принятие не заявлено.

## Результат

Причина — условие win_count==1 в victory_screen.gd: один победитель использовал новый VictoryBurst, несколько — старый PNG. Теперь все непустые итоги используют один процедурный компонент. Ветвь TextureRect/PNG и временный шейдер сглаживания удалены. Файл старого арта не удалялся, но ссылок на него в коде hub/games больше нет.

Размер контура по числу победителей сохранён с запасом под пиковый отскок: ширина не больше44%экрана в каждую сторону, высокий двухрядный вариант ограничен192px. VictoryBurst подстраивает ореол, кольцо лампочек и искры под фактический контур. Аватары/ники/лидер, TopBar, чат, лайки, кнопки и музыка не переделывались. Отключение движения через Prefs.parallax действует и для широких вариантов. При «Показать стол» весь компонент скрывается вместе с поверхностью, возвращается штатной кнопкой.

Файлы: hub/victory_screen.gd, hub/victory_burst.gd/.gdshader, tests/test_victory29_ui.gd, tests/test_victory_wide03.gd. У ореола дополнительно обнулена альфа на границе quad, чтобы и сам процедурный свет не давал слабый прямоугольный край. Прежняя передача: VICTORY_BURST_CODE_REVIEW_2026-11-02.md; её ограничение одиночным победителем теперь снято. Предыдущее описание сглаженного широкого PNG в REVIEW_BATCH_2026-11-03.md — история, заменено этим пакетом.
