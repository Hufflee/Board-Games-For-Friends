# ТЗ: «Длина волны» — третья игра сборника

Источник правил — `dlina_volny_rules.pdf`. Встраивается в «Настольные игры с друзьями»: стартовый экран, пати, Steam/IP, чат, стиль таверны.

## 1. Правила, как их реализует программа
- **Шкала** от левого понятия к правому (0…100). В начале раунда цветная зона ставится случайно; её центр всегда целиком виден (центр в пределах 3…97).
- **Зона очков**: центр ±2 — 4 очка, ±6 — 3 очка, ±10 — 2 очка; на границе засчитывается большее.
- **Карточки**: пары противоположностей («Горячее — Холодное»). Карточка двусторонняя: телепат выбирает одну из двух пар. Колода — своя (около 120 пар), перемешивается.

### Командный режим (основной)
- Две команды: «Левое полушарие» и «Правое полушарие», в каждой минимум 2 игрока. Первая ходящая команда начинает с 0 очков, вторая — с 1.
- **Ход**: телепат активной команды (по очереди внутри команды) видит зону, выбирает сторону карточки и пишет подсказку →
  его команда двигает стрелку (любой участник) и нажимает «Мы решили» →
  другая команда выбирает «Левее / Правее» (где центр относительно стрелки) → вскрытие.
- **Очки**: команда телепата — 2/3/4 по зоне (вне зоны — 0). Другая — 1 очко за верное «левее/правее», но ничего, если команда телепата попала в центр (4).
- **Правило догоняющего**: если команда телепата получила 4 очка и всё ещё проигрывает — она сразу ходит ещё раз (с новым телепатом).
- **Победа**: игра заканчивается, как только у кого-то 10+ очков; побеждает команда с большим счётом. Ничья — каждая команда делает ещё по ходу, побеждает набравшая за эти ходы больше; повторять, пока ничья не разрешится.

### Кооперативный режим (2+ игроков)
- Одна команда, телепаты по очереди. Колода из 7 карточек; попадание в центр — 3 очка и +1 карточка в колоду. Фазы «Левее/Правее» нет.
- В конце — оценка по таблице из правил (0–3 «Эта штука вообще работает?» … 25+ «Высший разум»).

## 2. Интерфейс
- Плитка «Длина волны» на стартовом экране. Игра по сети — через пати; плюс режим «На одном компьютере» (телепат смотрит на экран, остальные отворачиваются — перед показом зоны кнопка «Я телепат, показать»).
- **Лобби**: режим (команды / кооператив), выбор команды каждым игроком (кнопки «В левое / В правое полушарие»), «Перемешать команды» у хоста; в режиме «на одном компьютере» — добавление игроков по именам.
- **Стол**: большая полукруглая шкала по центру; синий экран закрывает цветную зону (у телепата и при вскрытии — открыт); красная стрелка, которую команда тащит мышью (у всех видно движение в реальном времени); карточка с двумя понятиями под шкалой; подсказка телепата крупно над шкалой; счёт команд дорожкой 0…10; составы команд с отметкой телепата.
- **Вскрытие**: экран отъезжает, очки всплывают, звук.
- Чат и реакции — как в других играх (обсуждать подсказку удобнее голосом или в чате).

## 3. Сеть
- Хост хранит зону и раздаёт её только телепату (кроме режима на одном компьютере). Стрелка синхронизируется во время перетаскивания (до ~15 обновлений в секунду).
- Разрешения: стрелку двигает только команда телепата, «Левее/Правее» выбирает только другая команда, подсказку даёт только телепат.

## 4. План
| # | Шаг | Готово, когда |
|---|-----|---------------|
| 1 | Движок правил + колода карточек | автотесты очков, догоняющего, победы и ничьей, кооператива |
| 2 | Сеть: хост, роли, синхронизация стрелки, команды в лобби | действия проходят через Net |
| 3 | Экраны: меню, лобби с командами, стол со шкалой, вскрытие, финал | партия на одном компьютере проходится мышью |
| 4 | Плитка на стартовом экране, правила, звуки | игра доступна из пати |
