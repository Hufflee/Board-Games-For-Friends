## Сделано
- **Азазель / «Повелитель ямы» 836 софтлочил игру** — отмена атаки, пока способность монстра ждёт своего броска (напр. Монстро II 372), возвращала «бросок атаки» без боя. Исправлено: продолжение приостановленных эффектов переписывается, плюс общая страховка «бой окончен → обычный ход».
- **Бомба на чужом ходу ломала игру (новый монстр не появлялся)** — монстр убит вне своего эффекта (вложенный/чужой эффект), пометка «дозаполнить слоты» терялась. Теперь пустые слоты монстров дозаполняются в спокойной фазе хода; фаззер проверяет «нет пустых слотов» (30 партий без нарушений).
- **Обычный «Сундук» после монстра — новый монстр не появлялся** — та же причина (дозаполнение); в прямых сценариях 701/702/699/713/719 слот заполняется.
- **Анх бросается дважды** — бросок 687 один раз за смерть (повторная запись смерти его больше не бросает).
- **Иерофант** — только «предотвратить до 2».
- **Красная пилюля 477** — случайный даритель только из других игроков.
- **Луна 640** — подсказка: верхнюю возьмёт тот, кто следующим берёт добычу (обычно активный).
- **Подсказка при раскладке карт на верх колоды** — «1-я сверху (возьмут первой)», «2-я сверху»…
- **Зависть 404 / Портал 432 «должен атаковать»** — теперь обязательная атака (ход не закончить, пока она не объявлена; механизм комнаты 792).

- **Нет выбора при штрафе** — без добычи и невечных предметов штраф проходит сам (−1¢); **обязательный выбор с единственным вариантом делается сам** (общая система).
- **Чужой ход: рубашки чужой руки убраны** — надпись «Карт добычи: N» под предметами ходящего.
- **Окно игрока (клик по персонажу)** — показывает «Карт добычи в руке: N · монеты · души».
