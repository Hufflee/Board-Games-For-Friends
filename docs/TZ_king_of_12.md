# ТЗ: цифровая версия «Дюжина короля» (King of 12)

Цель — сетевая версия настольной игры для 2–4 друзей через Steam (тестовое приложение Spacewar, AppID 480).
Godot 4.7.2, GDScript, Windows. Источник правил — `king_of_12_rules.pdf`.

## 1. Объём

Входит:
- Партия на 2–4 игроков по стандартным правилам (стр. 1–6 PDF), включая промокарты Коллекционер и Фавн.
- Сеть через Steam-лобби (друзья заходят по приглашению Steam или по коду лобби).
- Тестовый режим без Steam: прямое подключение по IP (ENet) и боты, чтобы проверять игру в редакторе.
- Боты могут занимать свободные места (по желанию хоста).

Не входит:
- Турнирные правила на 5–16 игроков (стр. 7–8).
- Публикация в Steam, достижения, сохранение партии, переподключение после обрыва.

## 2. Правила, как их реализует программа

### 2.1 Компоненты
- Кубик d12 у каждого игрока. Противоположные грани в сумме дают 13. Соседство граней — как у настоящего додекаэдра (нужно для Чародея).
- 12 базовых карт + 2 промо. У всех игроков одинаковый набор карт для партии.
- Жетоны ПО: 1 и 2 очка. Запас считается неограниченным (в коробке 9×«1» и 6×«2» — для онлайна ограничение не вводим).

### 2.2 Набор карт на партию (выбирает хост в лобби)
1. «Первая партия»: Рыцарь, Чародей, Оракул, Алхимик, Робот, Паразит, Голем.
2. «Случайный»: Рыцарь + 6 случайных из оставшихся 11; среди 7 должно быть ≥2 карт с символом кубика (меняют грань физически: Оракул, Чародей, Оборотень, Смутьяны, Торговцы). Если не выполнено — перетасовать заново.
3. «Вручную»: хост отмечает ровно 7 карт.
- Опционально: + 1 промокарта (Коллекционер или Фавн) — тогда в наборе 8 карт.

### 2.3 Значение кубика
- `грань` — физическое положение кубика; сохраняется до конца раунда.
- `значение` — грань + временные эффекты (Алхимик ×2, Робот +7, Паразит −7, Голем =12). Сбрасывается в начале каждого розыгрыша. Может быть <1 и >12.

### 2.4 Розыгрыш (trick)
1. **Выбор.** Каждый игрок закрыто выбирает карту из руки. Когда все выбрали — карты открываются одновременно.
2. **Отмена одинаковых.** Если одну и ту же карту выложили ≥2 игроков — все эти копии отменяются (без эффекта). Исключение — Леди (см. ниже).
3. **Эффекты** (только неотменённые карты), порядок:
   1. Если есть неотменённая **Леди** — эффекты всех остальных карт отменяются, переходим к шагу 4.
   2. **Торговцы**: каждый игрок передаёт кубик (грань) игроку слева (следующему по порядку мест).
   3. **Физические эффекты**: Смутьяны (все кубики → противоположная грань), Оборотень (свой → противоположная), Чародей (свой → одна из 5 соседних граней, выбор игрока).
      - Если у игрока с Чародеем одновременно действуют Смутьяны, порядок выбирает он сам: программа предлагает объединённый список итоговых граней из обоих порядков.
   4. **Числовые эффекты** (на значение): Алхимик ×2, Робот +7, Паразит −7, Голем =12. Применяются после физических.
   5. **Оракул** (последним): перебросить свой кубик.
   6. **Голем**, проверка: если после всех эффектов грань его кубика = 12, значение становится 1.
4. **Сравнение.** Все игроки (и с отменёнными картами тоже) сравнивают значения. Все кубики с одинаковыми значениями отменяются.
   - **Фавн**: если кубик владельца должен быть отменён, вместо этого кубик поворачивается на наибольшую грань, которой сейчас нет на верхних гранях других игроков; затем сравнение повторяется (Фавн срабатывает один раз).
5. **Победные очки.** Среди оставшихся: наибольшее значение — победитель (2 ПО), следующее — второе место (1 ПО).
   - **Рыцарь**: побеждает наименьшее значение, второе место — следующее по возрастанию.
   - **Шулер**: победитель получает 1 ПО, второе место — 2 ПО (с Рыцарем — то же для наименьших).
   - **Коллекционер** (после Рыцаря и Шулера): если кубик владельца был отменён, он становится победителем; кто должен был победить — занимает второе место.
   - Значение 0 может победить. Победителя или второго места может не быть.
   - **Леди, отменённая дублем**: среди игроков с Леди тот, у кого наименьшее значение, забирает жетон с наибольшим ПО у игрока с наибольшим значением. При равенстве этих значений — не применяется.
6. **Сброс.** Выложенные карты уходят в сброс игрока. Если у игроков в руке осталась 1 карта или у кого-то ≥8 ПО — раунд заканчивается, иначе новый розыгрыш (кубики не перебрасываются).

### 2.5 Конец раунда
1. Карты из сброса возвращаются в руку.
2. Сравниваются суммы ПО; равные суммы отменяются. Наибольшая оставшаяся — победитель раунда. Если никого не осталось — новый раунд без победителя.
3. Победитель выбирает карту из руки и кладёт под кубик (навсегда выходит из игры).
4. Вторая карта под кубиком — победа в партии. Иначе: жетоны в запас, все перебрасывают кубики, новый раунд.

## 3. Сеть

- Хост-авторитарная модель: вся логика — на машине хоста. Клиенты отправляют только действия (выбранная карта, выбор грани Чародея, карта под кубик, «готов»).
- Хост рассылает состояние каждому игроку; до вскрытия видно только «игрок выбрал карту», но не какую.
- Транспорт — высокоуровневый multiplayer Godot (RPC) поверх:
  - `SteamMultiplayerPeer` (GodotSteam) — для игры через Steam;
  - `ENetMultiplayerPeer` — для теста по IP/localhost.
- Steam: `steamInitEx(480)`, лобби «только для друзей» на 4 места, приглашение через оверлей Steam (Shift+Tab), вход по коду лобби, обработка `join_requested` и аргумента запуска `+connect_lobby`.
- Код не должен падать без Steam (в редакторе Godot из Steam аддон не грузится) — доступ к Steam только через `Engine.get_singleton("Steam")`.

## 4. Интерфейс (русский язык, 1280×720, растягивается)

1. **Главное меню**: имя игрока, «Создать игру (Steam)», «Войти по коду (Steam)», «Тест: хост по IP», «Тест: подключиться по IP», «Играть с ботами», «Правила», «Выход».
2. **Лобби**: список игроков (до 4), код лобби + «Скопировать», «Пригласить друзей» (оверлей Steam), «+ Бот / − Бот», выбор набора карт и промокарты (меняет только хост), «Начать» (только хост, 2–4 игрока).
3. **Игровой стол**:
   - игроки по кругу: имя, кубик (грань и текущее значение), жетоны ПО, карты под кубиком, статус «выбирает / выбрал»;
   - своя рука внизу: карты с картинкой, названием и текстом эффекта; клик — выбрать, повторный клик — подтвердить;
   - после вскрытия: выложенные карты у каждого игрока, отменённые перечёркнуты, журнал событий розыгрыша по шагам;
   - окна выбора: грань для Чародея, карта под кубик;
   - кнопка «Далее» после результата розыгрыша/раунда (продолжается, когда все люди нажали, или по таймеру 15 с);
   - экран победы.
4. **Правила**: краткая памятка и эффекты всех карт.

## 5. Графика

# Этап 2: бросок кубика и новый стол

## 8. Бросок кубика игроком
- В начале каждого раунда новая фаза **«Бросок»**: у каждого игрока на столе свой 3D-кубик (настоящий додекаэдр с числами 1–12, рендер через SubViewport).
- Игрок зажимает ЛКМ на своём кубике, тянет и отпускает. Скорость движения мыши задаёт силу броска: кубик летит по сукну, вращается, отскакивает от бортика, замедляется и ложится выпавшей гранью вверх. Затем возвращается на место игрока.
- Результат определяет хост (честный случайный бросок), анимация лишь доигрывается до выпавшей грани. Остальные игроки видят тот же бросок (направление и сила передаются по сети).
- Боты бросают сами; если человек не бросил за 30 с — кубик бросается автоматически.
- Розыгрыш начинается, когда бросили все.
- Эффекты карт, меняющие грань (Торговцы, Смутьяны, Оборотень, Чародей, Оракул, Фавн), показываются поворотом 3D-кубика.
- Соответствие граней модели правилам (соседство для Чародея, противоположные = 13) проверяется автотестом.

## 9. Стол и таверна
- Фон — пол таверны (текстура досок, CC0 Poly Haven) с тёплым светом и затемнением к краям, лёгкое мерцание «свечей».
- По центру — овальный покерный стол: деревянный бортик, кожаная окантовка, зелёное сукно (шейдер).
- Игроки по краям стола: табличка (имя, жетоны-монеты, звёзды побед в раундах, статус), у соперников — веер рубашек по числу карт в руке.
- Меню и лобби — на том же фоне.

## 10. Карты
- Рука — веер внизу экрана; при наведении карта приподнимается и увеличивается.
- Карту играют, перетащив её ЛКМ на стол (или двойным кликом). Пока не все выбрали, карту можно утащить обратно в руку.
- Сыгранная карта лежит на столе перед игроком: у остальных — рубашкой вверх, у самого игрока — лицом.
- Когда выбрали все, карты переворачиваются с анимацией; отменённые и подавленные помечаются.
- После розыгрыша карты уходят в сброс игрока.
- Карту под кубик победитель раунда кладёт, перетащив её на свой кубик.

# Этап 3
- Звуки (Kenney, CC0): кубик, карты, фишки, кнопки; кнопка «Звук: вкл/выкл».
- Поэтапное вскрытие: сначала одинаковые карты с пометкой «ОТМЕНЕНА» (≈2,6 с на группу), затем остальные по одной по часовой стрелке, своя — последней (≈2 с на карту, с подписью эффекта). Итоги розыгрыша показываются после вскрытия.
- До 8 игроков: места равномерно по овалу стола, при 6+ кубики уменьшены. Таймер автопродолжения: 45 с + 2 с на игрока.

# Этап 4: сделано
