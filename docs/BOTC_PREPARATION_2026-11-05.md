- Скрытая информация не попадает в публичные состояния, журналы, подсказки или чужие клиентские снимки. Смерть сама по себе не раскрывает роль. Особые права отдельных ролей проверяются отдельно.
- Ночные пробуждения, ответы, указания и постукивания — приватные кнопки и окна по правилам.
- Один компьютер используется только для соло-проверки разных мест, без требования полноценной совместной hot-seat партии.
