## Позднее дополнение — следующая проверенная точка

Ограничения ранней таблицы ниже частично закрыты:

- Обычное сохранение из любой вкладки запекает изменённую коробку в скрытых 2D-viewport, без создания лишнего 3D-мира. Сигнатура коробки исключает повторное запекание при изменении только карт/правил. Сохранение ждёт кадра; если за это время документ изменился, оно не подменяет его старым снимком. При аварийном закрытии исходник сохраняется отдельно, без ожидания GPU.
- Новая запечённая коробка проверена в настоящем шкафу и его упаковщике; кадры shelf_baked_dark/light. Перенос и размер слоя мышью, отражение, градиент, затемнение умножением на цвет, обводка и тень текста. Поворот пока числом, нет полной системы направляющих/ручки поворота.
- Добавлены отдельные экземпляры колоды по игрокам/командам, выбор начальной зоны, консервативный предел 300 по максимальному числу мест. Закрытая личная стопка скрыта даже от владельца; командная строка открыта своей команде.
- Импорт/выбор рубашки: закрытый view содержит только рисунок/размер без ID, строки и чисел. Крупный просмотр рубашки не раскрывает лицо.
- Панели «Я», соперников и команд работают с отфильтрованными ресурсами. На первом кадре восьми мест панели автоматически выросли по тексту и перекрылись: заменены фиксированными Panel и компактными строками, команда получила внутренний скролл. Повторный кадр panels_dark/light чистый. Расширенный редактор шаблонов планшетов ещё не сделан.
- Конверсия типа колонки преобразует все ячейки одной командой; неверная строка отклоняет всю операцию без потери исходных данных. Статическая проверка типов ячеек/ассет-метаданных дополнена.
- 26 встроенных шрифтов: исходный набор проекта и все 12 новых из ТЗ. Новые файлы и Rubik Wet Paint получены из официального [google/fonts](https://github.com/google/fonts/tree/6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec/ofl), commit/SHA/OFL/METADATA сохранены рядом. Rubik Wet Paint использует собственную лицензию, не OFL обычного Rubik. Для всех 26 проверены Я/ё в Godot. Текст интерфейса теперь Nunito с весом 600.

Свежие результаты: коробка/градиент/размер/сохранение другой вкладки/реальный шкаф/26 кириллических шрифтов — **128/0** (box13.log); UI с настоящим окном колонок — **98/0** (ui12.log); документ/конверсии — **52/0**; логика **69/0**, библиотека **38/0**, компоненты/приватность **51/0**, правила **17767/0**, пакет **180/0** (`check_*.log`). ## Реализовано

- Вместо заглушки — настоящая 3D-коробка во вкладке редактора, ПКМ вращает, колесо приближает. Четыре формы, толщина; игровой стол остаётся 2D. Грани Лицо/Задник/Корешок/Верх имеют отдельные SubViewport и 2D-режим.
- Слои заливки, изображения, многострочного текста. Порядок, видимость, замок, удаление; числовые координаты/размеры/поворот/прозрачность; перенос мышью по сетке одной отменяемой командой. До 64 слоёв на грань.
- Неразрушающий шейдер яркости/контраста/насыщенности/экспозиции/оттенка, сброс. Исходный импорт не изменяется.
- Запекание четырёх PNG до 1024 по длинной стороне и thumb, загрузка штатной коробкой хаба. Пустой задник повторяет лицо. Явная кнопка «Запечь и сохранить» дожидается кадра; обычное сохранение во вкладке коробки также сохраняет текущие отрендеренные поверхности.
- Начальный набор Russo One, Exo 2, Underdog, Nunito в editor/fonts с OFL и SOURCE. Фиксированные ключи встроенных ресурсов; пользователь не задаёт путь ResourceLoader. Можно выбрать свой импортированный кириллический шрифт. Расширенный набор из ТЗ пока не добавлен.
- Миниатюры в «Моих играх», копия последней сохранённой версии с новым UUID и ассетами; удаление удержанием перемещает в user://custom_games_trash без уничтожения файлов. Активную игру пати убрать нельзя. Черновик отдельно не дублируется — это указано в подсказке кнопки.
- Таблица показывает все колонки с горизонтальным скроллом; добавление типизированных свойств, удаление колонок/строк через undo. Поля лица связываются с колонками через UI, импортированный шрифт сразу применяется к заголовкам выбранной колоды.
- Логика: названия/порядок/фильтр фаз, логические переменные, текстовые сравнения, фильтры числовых переменных и исправленные значения блоков по умолчанию. Доступно окно ошибок/предупреждений.
- Блок show выводит крупную карту на две секунды только адресату; звук передаётся событием с ID из ограниченного встроенного набора, без пользовательских путей. UI не повторяет событие при обычном обновлении того же ID.
- Валидация форм/слоёв/колонок, пределы коррекции; повреждённые фазы/роли/грани черновика не передаются UI, открывается последняя корректная версия.

## Оставшиеся ограничения

Нет полной системы ручек трансформации/выравнивания/отражений/градиентных заливок/обводки текста и всех визуальных подсказок качества. Прямой перенос слоя есть, размер/поворот пока числами; режим за пределами грани не показывает 35% остатка. Толщина пока общий диапазон 0.04–0.12, без уменьшенных максимумов малых форм.

Планшеты, тиражирование колод по игрокам/командам, полноценный редактор слоёв лица/рубашек, позиции компонентов внутри свободной зоны и полный контроль порядка ходов ещё впереди. Сокеты — контролы выбора, не перетаскиваемые пазлы; нет миникарты/копирования цепей/шага по одному внутреннему блоку. Nunito пока выбран только как вариант заголовка коробки, текстовый UI прототипа ещё Exo 2. Расширенный OFL-набор/обучение впереди. Steam не проверен; докачка частичного буфера после перезапуска процесса не сделана.

Отдельная важная граница: при сохранении вне вкладки коробки нет перезапекания скрытых граней; для гарантированного актуального результата есть «Запечь и сохранить». Проверка реальной размещённой в шкафу именно этой новой запечённой коробки ещё нужна (старые custom-коробки и шаблоны проверены на этапе 3).
