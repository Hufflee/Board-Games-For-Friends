# ТЗ: «Оттенки и подсказки» (Hues and Cues) — пятая игра сборника

Источник: `Hues and Cues.pdf` (правила, 4 страницы). Встраивается в «Настольные игры с друзьями»
(стартовый экран, пати, Steam/IP, чат), со **своим современным спокойным стилем**.

## 1. Как играется по сети
- Подсказки **пишутся текстом** (показываются всем крупно) — так их нельзя «дорисовать» интонацией и видно историю.
  Голосовой чат — для общения, как обычно.
- Ведущий видит карту из 4 цветов и выбирает один; остальные ставят фишки кликом по клетке поля.
- Всё считает программа: рамка 3×3, очки, круги ведущих, переигровка при ничьей.

## 2. Правила, как их реализует программа
- **Поле**: 30 столбцов (1–30) × 16 строк (A–P) = 480 оттенков. Цвета сняты с поля из PDF
  (засвеченные фишками/подсветкой клетки восстановлены).
- **Игроки**: 3–8 (в сборнике максимум 8). У каждого свой цвет фишек.
- **Раунд**:
  1. **Карта.** Ведущий тянет карту — 4 случайных цвета с координатами — и тайно выбирает один.
     Вариант для новичков (опция хоста): ведущий выбирает любую клетку поля.
  2. **Подсказка из одного слова.**
  3. **Первые догадки** — по часовой стрелке от ведущего, по одному: клик по клетке.
     В одной клетке — только одна фишка.
  4. **Подсказка из двух слов** (до двух слов) — или ведущий **пасует**, и сразу подсчёт.
  5. **Вторые догадки** — против часовой стрелки, на любую свободную клетку.
  6. **Подсчёт**: рамка 3×3 вокруг загаданного цвета.
     - Угадавший точно — 3 очка; фишка в рамке — 2; фишка вплотную к рамке (вкл. диагональ) — 1.
     - Ведущий — 1 очко за каждую фишку в рамке (2 очка, если игроков трое).
- **Ограничения подсказок** (программа проверяет): нельзя базовые названия цветов
  (красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый, розовый, коричневый, белый, чёрный, серый —
  с любыми окончаниями), цифры и координаты, повтор подсказки, уже звучавшей в игре. Нельзя «светлее/темнее»
  во второй подсказке и предметы в комнате — на честность.
- **Конец игры**: 3–6 игроков — каждый ведущий дважды; 7–8 — по разу (хост может сменить: 1 / 2 круга).
  Побеждает больше очков. При ничьей — дополнительные раунды, ведущими становятся не претенденты на победу,
  пока один из лидеров не вырвется вперёд (если ведущих не осталось — общая победа).
- Хост может пропустить ход застрявшего игрока (вылетел из сети).

## 3. Стиль (современный, спокойный)
- Светлый тёплый фон (молочный/бумажный), мягкие тени, крупные скругления, много воздуха.
- Палитра интерфейса приглушённая: графит для текста, шалфейный и пыльно-синий акценты — всё яркое
  остаётся только на самом поле.
- Шрифт без засечек с кириллицей (Manrope, OFL).
- Фишки игроков — круглые «таблетки» с мягкой тенью, плавные анимации появления, рамка подсчёта
  выезжает поверх поля.
- Спокойная фоновая музыка (CC0), мягкие звуки щелчков.
