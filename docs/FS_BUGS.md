# Four Souls — реестр багов

Единственный актуальный список. Создан 31.10.2026 (этап 0 плана `docs/FS_BUGFIX_PLAN_2026-10-31.md`).
Старые отчёты — `docs/fs_archive/` (читать только при разборе конкретной строки).

**Правило ведения:** нашёл — строка сюда; починил — статус «закрыт» + имя теста/кейса. Строка без теста закрытой не считается.

## Легенда

- **Класс:** A — блокер (зависание, потеря/копия карты, утечка монет, рассинхрон); B — базовое правило;
  C — автоматика карты срабатывает неверно; D — панель эффекта не может выразить текст; E — UI; F — сеть/Steam.
- **Статус:** `открыт` · `в работе` · `закрыт (тест)` · `код есть → сверить кейсом` (автоматика написана, но отдельного
  поведенческого кейса нет — проверяется на этапе 1) · `выполнимо вручную → пометить manual` (не баг, если в UI есть пометка) ·
  `тест устарел?` (падает тест, а не игра — сначала разобрать).
