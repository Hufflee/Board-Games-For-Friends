# ТЗ: новое главное меню — неоновая ретро-комната со шкафом настольных игр

Замена «таверны» в главном меню и базовом интерфейсе. Референс — пользовательская картинка: детская комната
90-х ночью, фиолетово-розовый неоновый свет, светящиеся звёзды на стене, ЭЛТ-телевизор, постеры, лавовая лампа.

## 1. Что видит игрок
- **3D-комната** (Godot, без Blender — всё из примитивов): стены, пол-ковёр, окно с жалюзи и ночным городом
  за ним, кровать, тумбочка с лампой и часами, ЭЛТ-телевизор на тумбе (на экране — пиксельная заставка),
  лавовая лампа, скейтборд, светящиеся звёзды на стене, неоновые постеры (наши игры, а не чужие фильмы —
  чужие постеры использовать нельзя).
- Свет: фиолетово-синий заполняющий, розовый акцент от лавовой лампы и неона, бирюзовое свечение телевизора;
  объёмное свечение (glow) у неоновых элементов. Лёгкое «дыхание» света и покачивание камеры.
- **Шкаф для настольных игр** — 4 ячейки по вертикали × 1 по горизонтали (позже можно расширить).
  Камера стоит так, чтобы **все 4 полки были видны сразу** (дальше, чем в референсе-видео).
- В ячейках **коробки стоят вертикально, как книги**, торцом к игроку, с лёгким наклоном (референс —
  видео Dire Wolf Game Room): на торце — название и цветной корешок.
- **Наведение** на коробку: она подсвечивается неоновой обводкой и немного выезжает из шкафа.
- **Клик**: коробка плавно вылетает из шкафа и останавливается перед игроком, развернувшись **обложкой к нему**
  (как в видео-референсе), карточка игры появляется справа от коробки.
  Рядом появляется карточка игры: название, описание, число игроков, время партии, кнопки
  «Играть» / «Играть всей пати» (хост) и «Назад» (коробка возвращается в шкаф). Колесо мыши / стрелки — соседняя игра.
- **Пати** — та же логика, что сейчас (создать / войти / участники / код / пригласить / чат), но в неоновой панели
  сбоку. Настройки и выход — неоновые кнопки.

## 2. Обложки
- Коробка: тело — цветной параллелепипед, лицевая сторона — картинка обложки, торцы — название (Label3D).
- Обложки: реальные обложки игр, скачанные из интернета (только для личной игры, как и остальной арт),
  или из присланных PDF, где они есть (Hues and Cues, Ready Set Bet). Квадратные, ~1024 px.

## 3. Базовый интерфейс — неоновое ретро
- Тема `K12UI` (общая для стартового экрана, меню/лобби «Дюжины короля», «Перудо», «Длины волны», чата, настроек)
  перекрашивается: тёмно-фиолетовые полупрозрачные панели, неоновые рамки (розовый / бирюзовый) со свечением,
  шрифты с кириллицей в ретро-духе (OFL): заголовки — **Russo One**, текст — **Exo 2**, акценты — **Press Start 2P**.
- Столы «Дюжины короля», «Перудо», «Длины волны» (сукно, деревянный фон) пока остаются — их переделку обсудим
  отдельно. У остальных игр свой стиль, их не трогаем.

## 4. Технически
- `hub/hub.tscn` → 3D-сцена (`Node3D` + `WorldEnvironment` + свет) + слой UI (`CanvasLayer`).
- Коробки — отдельная сцена/скрипт `GameBox` (MeshInstance3D + обложка + торец + анимации).
- Выбор мышью — луч из камеры (`PhysicsRayQueryParameters3D`) по коллайдерам коробок.
- Производительность: без SDFGI/теней на всех лампах; одна-две тени, glow в WorldEnvironment.

## 5. План
| # | Шаг | Готово, когда |
|---|-----|---------------|
| 1 | Обложки 7 игр (скачать / из PDF), шрифты | файлы в проекте |
| 2 | Комната и свет | сцена открывается, похожа на референс по настроению |

| 4 | Пати, настройки, выход в неоновой панели | всё, что умел старый экран, работает |
