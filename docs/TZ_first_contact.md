# Первый контакт

Правила из b5cbce9050d28ab0a74cecea3fb85fcd.pdf, предметы из Workshop 1827359044. Поле 5×5. Задания раздаёт хост, подсветку видят только инопланетяне. Отдельных карт задания нет. В ход землян каждый выбирает от одного до пяти примеров. В ход инопланетянина признаки объявляются условными символами, земляне голосуют тайно. Поддержаны лёгкая, сложная партии и вариант для двух-трёх игроков.

Для цифровой версии сочетание «признак → знак» выдаётся случайно. Инопланетяне набирают подсказку готовыми знаками, включая отрицание. Земляне ведут индивидуальные заметки. Очки знания языка используются при ничьей.
