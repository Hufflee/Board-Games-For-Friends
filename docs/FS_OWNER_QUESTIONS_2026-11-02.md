# Four Souls: вопросы и принятые допущения — 02.11.2026

По поручению владельца вопросы не прерывают работу; неоднозначности решаются самостоятельно и сохраняются здесь. Задать оставшиеся вопросы после выполнения.

1. Steam-приёмка: владелец подтвердил возможность партии с другом на двух аккаунтах. Организация самой проверки остаётся после готовой автоматизации; готовность обычных наград не подменять испытанием транспорта.
2. Принято: напечатанные ресурсы награды автоматизировать отдельно от сложного текста смерти. Если часть текста ещё ручная, панель явно говорит, что награда уже начислена; повторное ручное начисление награды блокируется. Не выдавать это за полную поддержку способности карты.
3. Вопросов о снятии запрета/модулях/комнатах из раздела12 плана больше нет: они решены поручением31.10.
4. Принято для 528: удваиваются ресурсы reward box (в том числе количество урона274), душевая ценность отдельно и не удваивается. У275 физическая карта становится предметом один раз. Требуется последующее адресное расширение редкого порядка смерти получателя во время текста/призового броска; текущая естественная партия не доказывает все такие ветви.
