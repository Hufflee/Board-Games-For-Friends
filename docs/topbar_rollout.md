# Перенос верхней полосы (TopBar) во все игры

Образец — «Большая бродилка»: `games/brodilka/ui/br_table.gd`, где `TopBar.make(...)` вызывается в `_ready`.
Компонент — `hub/top_bar.gd`, его не менять. Кнопки паузы и зрителя в углу `PauseLayer` сам прячет, когда в сцене есть полоса.

## Что сделать в `<игра>_table.gd`
1. **Убрать** со стола:
   - старый ряд общих кнопок («Правила», «Настройки», `ThemeToggle`, «Журнал», «Выйти» / «Завершить партию» / «Покинуть пати»);
   - отдельные часы `TurnClock.top_center` / `top_right` / `TurnClock.new()`;
   - угловой чат `K12ChatPanel.new()` вместе с `restyle_chat` для него;
   - строку «Раунд N…» / фазу, если она дублирует то, что пойдёт в полосу.
2. **Создать полосу:**
   ```
   _top = TopBar.make(self, "<Название игры>", func(t, z): return <Style>.button(t, z), null, <цвет текста>, <жирный шрифт игры>)
   ```
   - `null` — фон прозрачный: должен совпадать с фоном игры.
   - Цвет текста — читаемый на фоне игры: на тёмном фоне светлый, на светлом тёмный.
   - Свои кнопки игры (Правила, Настройки, тема, Журнал, Выйти с прежним `LeaveGuard`) создать как раньше и положить в `_top.actions`; «Выйти» — тихой (QuietButton, если она есть в теме игры).
   - Чат — `_top.chat`: при необходимости перекрасить его тем же `restyle_chat`.
3. **Информация в полосе.** `_top.info.text` обновлять в обработчике состояния: раунд / чей ход / фаза — то, что раньше было в строке раунда. Коротко: «Раунд 2 из 6», «Ход: Имя».
4. **Раскладка.** Всё содержимое стола опустить на `TopBar.HEIGHT` (48 px): верхние отступы, `_layout`, якоря. Ничего не должно залезать под полосу. `ChatBubbles.attach` оставить, при необходимости поправить отступ.
5. **Проверка:**
   ```
   godot --headless --path . res://tools/_fuzz/compile.tscn
   GAME=<id> SCENE=res://games/<id>/ui/main.tscn BOTS=3 WAIT=3 OUT=<папка> NAME=<имя> godot --path . --resolution 1280x720 res://tools/_shot/any_shot.tscn
   ```
   Посмотреть скриншот: полоса сверху, фон полосы — фон игры, ничего не перекрывается, всё читается.
   Godot: `/d/SteamLibrary/steamapps/common/Godot Engine/godot.windows.opt.tools.64.exe`.
   `--import` не запускать: параллельно работают другие.
