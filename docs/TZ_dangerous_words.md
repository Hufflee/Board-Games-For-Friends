# ТЗ: «Опасные слова» — четвёртая игра сборника

Источники: `Опасные слова - Rules.pdf`, `Карты.pdf` (слова, монстры, проклятия), `Тайлы поля.pdf` (комнаты подземелья),
`Жетоны.pdf` (фигурки монстров, команд, факелы), лист слов-ловушек.
Встраивается в «Настольные игры с друзьями» (стартовый экран, пати, Steam/IP, чат), но со **своим жутковатым
хеллоуинским стилем** (не общая «таверна»).

## 1. Как играется по сети
- Объясняют **голосом** (Discord и т. п.) — как в настольной игре. Программа ведёт всё остальное:
  выдаёт секретные слова, хранит списки ловушек, считает время, догадки, двигает фигурки, монстра и проклятия.
- Кнопки:
  - **у объясняющего** — «Отгадали!» (команда назвала слово);
  - **у соперников** (команды, записавшей ловушки) — «Ловушка!» (с выбором сработавшего слова), «Нарушение»,
    «+1 неверная догадка» (счётчик до 5);
  - **у отгадывающей команды** — поле для догадок текстом (необязательно): если в догадке есть секретное слово,
    засчитывается автоматически; иначе считается неверной догадкой.
- Таймер-песочные часы; время на раунд задаёт хост (по умолчанию 60 с), отсчёт начинается через 3 с после того,
  как объясняющий увидел слово.

## 2. Правила, как их реализует программа
- **Команды**: две, в каждой минимум 2 игрока. Факел (объясняющий) переходит по кругу внутри команды каждый раунд.
- **Подземелье**: комнаты 3, 4, 5, 6, 7 (хост может выбрать другой набор из 1–10). Обе команды стартуют в первой,
  монстр — в последней. Две закрытые карты проклятий: у второй комнаты и у комнаты перед монстром.
- **Слова**: переписаны с карт (100 сторон × 8 слов). Разделить на «обычные/фэнтези» по картам не удалось (на каждой стороне слова вперемешку), поэтому колода общая. Секретное слово — случайное из восьми слов случайной карты.
- **Раунд**:
  1. **Ловушки.** Обе команды одновременно видят секретное слово, которое будет объяснять соперник,
     и записывают ловушки — столько, каков номер комнаты соперника. Список общий для команды (все видят правки),
     «Готово» — когда команда договорилась.
  2. **Объяснение.** Первой ходит отстающая команда; если команды в одной комнате — по очереди (как «сияющая книга»).
     Провал: ловушка, нарушение, 5 неверных догадок, время вышло. Успех — команда идёт в следующую комнату.
  3. **Если обе провалились** — монстр сдвигается на комнату ближе; если он входит в комнату с проклятием,
     проклятие сдвигается тоже (каскадом).
- **Проклятие**: когда команда начинает раунд в комнате с проклятием, оно открывается и действует на неё
  (на обе, если обе там) этот раунд, затем сбрасывается. Механические эффекты (Слово ужаса — отступить на комнату,
  Обезвреженная ловушка — вычеркнуть слово по номеру, Безумные каракули — до 10 ловушек на время) программа
  выполняет сама; остальные (Тьма, Эхо, Окаменение, Потоп, Импульсивность, Слабоумие, Иллюзорная змея) показываются
  крупно и соблюдаются честно, нарушение отмечают кнопкой «Нарушение».
- **Монстр**: команда, начавшая раунд в его комнате, сражается: действует правило монстра (числовые — программа,
  остальные — честно). Отгадали — победа. Обе отгадали — общая победа; ни одна — ещё раунд (монстр больше не ходит).
  Монстры: Тролль, Дракон, Мумия, Демон, Вампир; опция «злобные версии» (со звёздочкой).
- **Лимит 8 раундов** — потом побеждает монстр.

## 3. Стиль (жутковатый / Хеллоуин)
- Фон: ночное подземелье — чёрно-фиолетовый градиент, туман (шейдер), луна, летучие мыши, паутина по углам.
- Акценты: тыквенно-оранжевый, ядовито-зелёный, призрачно-голубой; мерцающие свечи.
- Шрифты (OFL, с кириллицей): «капающий» заголовочный (Rubik Wet Paint) и читаемый основной (Rubik).
- Арт из присланных PDF: комнаты подземелья, фигурки монстров и команд, факелы, карты проклятий и монстров.
- Звук: жуткая музыка, скрипы, вой (CC0, если найдутся), удар гонга при ловушке.
