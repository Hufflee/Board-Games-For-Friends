# UI-гайды (uidesign.tips/ui-tips) — выжимка для игр

Источник: https://www.uidesign.tips/ui-tips (39 советов). Ниже — пересказ и как применяем у себя.

## Иерархия и текст
- **Иерархия**: главное — крупнее/жирнее, второстепенное — меньше контраста (приглушённый цвет/прозрачность), шкала размеров с постоянным шагом (~1.25×), связанные элементы группировать.
- **Заголовок**: жирный заголовок, подзаголовок светлее, нормальный межстрочный интервал, выравнивание по левому краю для блоков текста.
- **Длина строки**: не растягивать абзацы на всю ширину — 500–700 px (≈60–80 символов).
- **Разделение пробелом**: группы разделять отступами, а не линиями/рамками везде.
- **Выравнивание неровных элементов**: одинаковая ширина у однотипных кнопок/плашек (по самому широкому).

## Кнопки и действия
- **Один главный CTA** на экране — самый заметный (заливка акцентом); остальные — вторичные.
- **Единообразие кнопок**: одинаковый стиль и формулировки во всей игре.
- **Опасные действия приглушать** (выйти, удалить, сдаться): вторичный стиль, в стороне; безопасное действие — главное. Подтверждение перед необратимым.
- **Понятные подписи**: на кнопке — конкретное действие («Выйти из партии», а не «Да»); пользователь заранее знает, что произойдёт.
- **CTA в конце пути взгляда** (Z-паттерн): главная кнопка — справа/внизу блока.
- **Кнопка вместо ссылки** для важных действий.

## Состояния и выбор
- **Выбранное выделять фоном** (не только рамкой/текстом); активная вкладка — подсвечена.
- **Различать несколькими признаками** (цвет + форма/иконка/текст), не только цветом — для дальтоников подписи у цветов.
- **Пустые состояния** — подсказка, что делать дальше.
- **Подсказки к полям**: плейсхолдер даёт пример/формат, а не повторяет подпись; для чисел — степпер, не текстовое поле.

## Формы и детали
- **Скругления**: внешний радиус ≈ внутренний + отступ (≈2× у вложенных карточек).
- **Отступы в карточках**: у краёв с текстом — больше воздуха; ничего не прилипает к краю экрана.
- **Иконки с подписями**; горячие клавиши показывать рядом с кнопкой.
- **Аватары/прозрачные картинки** — с тонкой рамкой/подложкой.
- **Основной цвет бренда** — только для самого важного, остальное — его оттенки.
- **Карточки должны выглядеть кликабельными** (кнопка/явный признак, не только hover).
- **UX важнее «конверсии»**: не ставить кнопки так, чтобы по ним промахивались.
