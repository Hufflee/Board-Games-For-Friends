# Four Souls — карты для ответов

Дополнение02.11: ручное «Срабатывание по условию» предмета — отдельный `item_trigger`, без поворота и событияactivate. Оно не блокируется10с чужого хода; новыеloot/activate по-прежнему блокируются. Полностьюauto повторно не запускается, наступление непокрытого условия проверяют игроки. У70 вручную доступна пассивная часть начала хода отдельно от копирования. Проверки/ограничения — `docs/FS_MANUAL_CONDITIONS_2026-11-02.md`.

Каталог `games/four_souls/art/response_catalog.json` охватывает все **913** импортированных карт: id, исходный тип, категория времени применения и основание. Он используется FSData. Воспроизведение: `python tools/audit_four_souls.py --project .` после импорта мода.

|---|---:|---|
| Лут | 221 | Чужой ход при доступном розыгрыше, обычно через готового персонажа |
| Только свой ход | 1 | Солнце: дополнительный ход обусловлен своим ходом |

| Не личная карта для ответа | 388 | Монстры, события, комнаты, персонажи и бонусные души |

Разбор использует типы всех записей мода, общие правила времени применения и отдельную визуальную проверку 45 вечных предметов без Lua-типа, шести особых сокровищ и Солнца. Среди особых сокровищ «Экспериментальное лечение» имеет платную способность, «Ящик Пандоры» — поворотную; остальные четыре пассивные. Брелок в руке разыгрывается как лут, после размещения среди предметов считается пассивным.

Специальные цели, цены, счётчики и пассивные условия по-прежнему исполняются по тексту карты через панель эффекта. Каталог определяет группу интерфейса и тип активации; он не автоматизирует все индивидуальные эффекты. Повёрнутый предмет можно прочитать, но поворотная кнопка отключена.

Основание каталога: [официальные правила](https://foursouls.com/wp-content/uploads/2022/01/Booklet_cropped.pdf), [типы карт](https://foursouls.net/rules/cards/), [структура хода](https://foursouls.net/rules/turn-structure/). Правило времени цифрового проекта обновлено владельцем01.11: стек закрывается после5с тишины, новая карта начинает отсчёт заново. Применение своих карт в чужой ход — только первые10с хода, также для ответов на смерть/кубик. Пасов нет; исходный текст каталога не отменяет эти ограничения. Локальное открытие руки не перезапускает таймер.

Рука соперника в `get_view` представлена только количеством карт; рубашки строятся без id скрытых карт. Сортировка своей руки локальна, не меняет серверные колоды.
