# Редактор — фундамент 1, 01.11.2026

Автор/самопроверка: Codex. Это чистое ядро, не готовый редактор и не независимая приёмка.

Добавлены каталог разрешённых JSON-блоков, проверка определения, хостовое состояние, ограниченный интерпретатор и три исходных JSON-примера (карточная гонка, больше/меньше, ставка на количество троек в закрытых d6). Последний пример проверяет механику ставки и проверки, а не воспроизводит полные правила Перудо.

Состояние содержит карты/зоны, общие/личные/командные переменные, закрытые кубики, фазу, ход, журнал, ограниченный trace и сериализованные кадры продолжений. RNG хранится строкой, чтобы JSON не терял 64-битную точность. Ошибка действия откатывает состояние и RNG. Перечисление допустимых действий не расходует RNG. Закрытые карты в view не имеют id/полей; выбор карты доступен только из видимых карт. Временный показ гаснет через 2 секунды. Приватные подсказки не попадают в общий журнал. Ответ на бросок подтверждает жест, результат выбирает хост.

Песочница работает без цепочек: свободные зоны разрешают брать верх закрытой колоды, двигать видимые карты между доступными свободными зонами, переворачивать и перемешивать. Чужую личную/командную зону трогать нельзя. Пакеты пользовательского кода и загрузка ресурсов не используются.
