# Визуальный дизайн — выжимка (NN/g «Good Visual Design», Process «How to get better at visual design»)

Дополняет [ui_tips.md](ui_tips.md). Статья uxplanet «50 design styles» не прочитана (закрыта проверкой Cloudflare).

## Принципы NN/g
1. **Сетка и выравнивание.** Колонки + межколонники; всё выравнивается по одной сетке на всех экранах игры.
   Узкие межколонники — для картинок/карт, широкие — для текста.
2. **Типографская система.** Иерархия — прежде всего размером; **не больше ~3 размеров** текста на экране
   (заголовок / основной / подпись). Читаемый шрифт; длинный текст — короче строки, чуть больше интерлиньяж.
   Одно семейство шрифтов, один цвет текста — уже выглядит собранно.
3. **Стратегическая палитра.** Монохром или **2 основных цвета** (+ нейтральные). Избегать кислотных/неоновых
   насыщенных цветов — отвлекают (исключение — осознанный стиль, напр. неоновый хаб). Сложные гармонии — только с опытом.
4. **Полезные изображения.** Картинка должна нести информацию, а не шум. Если фон спорит с текстом —
   подложка между ними (полупрозрачная/«стеклянная» панель). Главный объект — по центру своей ячейки сетки.
5. **Главное:** каждое решение — осознанное и **последовательное** во всём продукте.

## Process (как расти в визуальном дизайне)
- Насмотренность: собирать референсы (сайты, приложения, книги, коробки игр) из своей темы, повышать планку.
- Учиться копированием: воссоздать то, что нравится, чтобы понять, как оно собрано.
- Регулярная практика: шрифт, цвет, картинки, сетка, композиция.
- На реальном проекте: структура и иерархия, визуальный рассказ, эмоция; обратная связь от людей.
- **Стайлборд (art direction)** перед большой работой: быстро показать настроение/цвета/шрифты и согласовать,
  потом уже рисовать экраны.
- Свой почерк: повторяемые паттерны, компоненты, дизайн-система.

## Как применяем в играх
- У каждой игры — своя мини-дизайн-система: 1 шрифт-заголовок + 1 текстовый, 3 размера, 2 основных цвета + нейтральные.
- Единая сетка/отступы (8 px шаг) на меню, лобби, столе.
- Перед крупной переделкой стиля — стайлборд на согласование.
