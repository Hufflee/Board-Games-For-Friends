# Для ревью: многослойное лицо карты — 02.11

Позднее дополнение: прежнее ограничение нативного выбора OptionButton снято настоящим Windows-вводом мышью/Down/Enter в обеих темах. См. EDITOR_NATIVE_GUIDES_REVIEW_2026-11-02.md; остальные старые ограничения ниже относятся к моменту первой передачи.

Автор и фактический проверяющий: Codex. Передача только через markdown, без Claude CLI. Независимое ревью дополнения не выполнено.

Во вкладке «Элементы» появился «Редактор лица карты». Старое оформление сохраняется, пока автор явно не нажмёт «Создать слои из текущего вида». Шаблон общий для колоды: текст и рисунок можно связать с колонкой таблицы, переключая строки для предпросмотра. Доступны прямоугольник/овал, текст, рисунок, собственные шрифты из ассетов, цвет, непрозрачность, порядок, видимость и закрепление.

На холсте работают выбор, перенос, все четыре угла, поворот, панорама и зум. Трансформация записывается одной командой undo. Рисунок импортируется через существующий нативный диалог, его размер сохраняется в пикселях холста; ограничение импортируемого ассета 2048 px остаётся. Слои лица копируются между проектами вместе с рисунком/шрифтом; отсутствующие колонки отклоняются до изменения проекта. При удалении колонки её привязки снимаются и возвращаются через undo.

Общий 2D-renderer используется редактором, столом и крупным просмотром; игровой стол не зависит от 3D-редактора коробки. Холст шаблона равен четырём физическим пиксельным размерам карты. В сетевом состоянии шаблон передаётся один раз на колоду, а не копируется в каждую карту. Содержимое привязок разрешается по данным видимой карты; закрытая чужая рука не получает лицо/ID. Квадратные карты сохраняют пропорции при крупном просмотре.

Дополнительно исправлен реальный дефект старого буфера: длинная base64-строка картинки/шрифта ошибочно попадала под предел обычного текста 4096 символов. Теперь обычные данные и метаданные проверяются отдельно от бинарного поля; прежние пределы объёма, форматы и SHA-256 сохранены. Проверены настоящая шумовая картинка больше старого предела, шрифт, чрезмерный обычный текст и подменённые байты. В светлой теме восстановлен контраст LinkButton, включая ссылки справки.
