# Редактор: буфер цепочек и блоков — 02.11.2026

Продолжение редактора после локальной приёмки Four Souls. Автор и фактический проверяющий — Codex; независимого ревью пока нет. Резервные копии изменённых файлов: `backups/editor_logic_clipboard_20261102/`.

## Поведение

- Слева во вкладке «Логика» можно скопировать и вставить целую цепочку события. В свойствах — выбранный блок со всеми вложенными ветвями. Пустое событие тоже принимает блок из буфера.
- «В ветвь „Да“ / „Иначе“ / внутрь цикла» задаёт место следующей вставки. Новый блок или цепочка выбирается автоматически. Отмена и повтор выполняются одной командой; после отмены целой цепочки остаётся корректное выбранное событие.
- Используется настоящий системный буфер с существующим JSON-форматом редактора. При вставке всем исполняемым блокам назначаются новые ID; ссылки выражений на переменные и зоны не переименовываются. Нумерация не сканирует уже выданные номера повторно для каждого вложенного блока.
- Можно вставлять между проектами с совместимыми именами зон, ресурсов и кнопок. Отсутствующая ссылка или неподключённый словарь отклоняет всю вставку. Фазы и схема проверяются общим валидатором. Зависимые ресурсы и зоны автоматически не создаются.
- Сохранились ограничения и проверка ассетов прежнего буфера. Неподходящий путь не позволяет вставить блок в таблицу компонентов или выражение. В один массив вставляется не более 200 блоков.
- Выделение событий, фаз и блоков теперь читается в светлой теме; выбранный фон сохраняется при наведении. Общий стиль `cg_style.gd`, изменённый другой сессией, не правился.
- Копирование читает текущую коллекцию в момент нажатия. Правка свойства без перестроения панели больше не копирует прежнее значение; общий обработчик исправлен также для слоёв и элементов.
