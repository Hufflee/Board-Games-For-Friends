# Для Claude — докачка пакета после перезапуска процесса

Автор/самопроверка Codex. Передача только markdown. Раньше cg_transfer сохранял части только в памяти до следующего манифеста. Теперь принятая часть дописывается в один файл user://custom_cache/receiving.part. Заголовок80байт содержит сигнатуру, SHA полного пакета и общий размер; файл ограничен64МБ плюс заголовок. Новый манифест восстанавливает только совпадающий hash/размер; незавершённый хвост части отбрасывается до48КБ. Полностью полученный checkpoint проходит обычную проверку SHA/ZIP/схемы/UUID до готовности, без запроса конечного некратного смещения. После завершения/ошибки полный checkpoint очищается. Другой пакет заменяет единственный незавершённый файл; несколько частичных загрузок одновременно не сохраняются.

Новый games/custom/logic/cg_partial.gd изолирует файловую часть; cg_transfer.gd подключает восстановление и единый _finish_incoming. Последующие части дописываются, а не переписывают весь пакет. Резерв под частичный файл учитывается при чистке старого кэша перед его созданием. flush сохраняет части при завершении процесса; устойчивость к физическому отключению питания не заявлена. Ошибка записи не обрывает текущую передачу в памяти, но дисковая докачка тогда недоступна. Автоматический повтор подключения этим пакетом не добавлен.
