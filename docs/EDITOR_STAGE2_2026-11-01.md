# Редактор — стол и Net, 01.11.2026

Автор и самопроверка: Codex. Независимое ревью Claude ожидает авторизации CLI (две попытки этапа 1 завершились ошибкой OAuth). Пакет не объявлен независимым ревьюером принятым.

Добавлены `games/custom/ui/main.tscn`, `cg_app.gd`, `cg_table.gd`, `cg_style.gd`, мост `logic/cg_session.gd` и ветка cg в Net. Общий 2D-стол строит зоны/текст/счётчики из JSON, использует TopBar, K12TableCard с собственным простым лицом/рубашкой и TossDie. Есть крупный просмотр, клик/перенос карты, адресные выборы и бросок жестом, темы, локальные места без ботов, команды/роли в лобби. Хост проверяет действия по ревизии и реальному peer; клиентское поле as не меняет место. Завершение использует общий экран победителей.

В ядро добавлены события броска и ручного переноса, однократный пропуск будущего места, ограничение шапки по роли, хостовый таймер и timeout, сбрасываемый при фазе/ходе. Больше/меньше теперь действительно спрашивает направление перед открытием следующего числа. Интерфейс получает русские названия вместо внутренних id примеров; целые числа показываются без .0.
