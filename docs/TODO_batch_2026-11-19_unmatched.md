## Вопросы и принятые решения

- В PnP третьего тома есть иллюстрации карт, а отдельный обновлённый лист фишек в доступных локальных материалах не найден. Публичный API Яндекса не ответил. Для трёх фишек выбраны различимые портреты из уже предоставленных русских карт; новые картинки не генерировались. Прежние вырезки Workshop заменены.
- Метки T-Rex pins не следует превращать в выдуманные бонусы или действия. Они удалены с растров. Механика двухклеточного Ти-Рекс будет нужна при добавлении самого героя; Бигфут и большая Алиса такими бойцами не являются.
- Сохраняем текущую линию патчей от 0.8.12, без принудительного перевода существующих игроков на новую базу. Полная локальная папка обновляется отдельно; на GitHub публикуется запрошенный патч.
- Новая локальная сборка помещается рядом с предыдущей: `build/releases/0.8.12/0.9.1.3/`. Предыдущая папка остаётся резервной копией.
