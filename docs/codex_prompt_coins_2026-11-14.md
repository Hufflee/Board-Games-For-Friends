# Промт для Codex: монетки антистресса четырёх новых игр (14.11)

Сделай монетки антистресса (hub/fidget.gd) для четырёх игр: Кольт Экспресс (`colt_express`), Первый контакт (`first_contact`), Green Team Wins (`green_team_wins`), В общих чертах (`in_broad_strokes`). Для каждой игры — четыре облика: обычная светлая, обычная тёмная (`_dark`), секретная светлая (`_secret`), секретная тёмная (`_dark_secret`). Итого 16 листов.

## Общие требования (решения владельца)
- Мультяшно, не реалистично: крупные читаемые символы, мало мелких деталей, слегка неровные линии «от руки» с небольшими промахами, приглушённые цвета, рисованный объём без глянца, сильных бликов, направленного света и реалистичной фактуры.
- Формат как у остальных: лист 1774×887, прозрачный фон, слева орёл, справа решка (по 887×887). Рисовать кодом на Python + PIL поверх `tools/coin_common.py` (wobble, outline, volume, edge, glow, save_sheet, preview). Один скрипт на игру: `tools/coin_<id>.py`, рисует все четыре облика (или отдельный `_secret.py`, как у Things in Rings).
- Тёмный вариант — та же монета под тёмную тему игры (цвета из DARK), не просто затемнение.
- Секретная монета узнаваемо та же, что обычная (символы и стиль те же), но «улучшенная»: заметнее, ярче, праздничнее — как у Gloom и Things in Rings. Открывается пятью орлами подряд (порог не менять).
- Файлы: `hub/art/coins/<id>_coin.png`, `<id>_dark_coin.png`, `<id>_secret_coin.png`, `<id>_dark_secret_coin.png`; источник — строкой в `hub/art/coins/SOURCE.txt`.

## Идеи по играм (символы — крупно, одна мысль на сторону)
- **Кольт Экспресс** — вестерн-плакат. Обычная: латунь/медь на выгоревшей бумаге, орёл — паровоз сбоку, решка — звезда шерифа или мешочек «$». Тёмная — ночная: луна, тёплые жёлтые окна. Секретная — «Разыскивается»: золото, звезда шерифа с лучами, дырка от пули на ободе.
- **Первый контакт** — папирус + язык корабля. Обычная: песчаник/охра, орёл — глаз-иероглиф или анкх, решка — инопланетный знак (△ или ◐) бирюзой. Тёмная — ночь в пустыне, знак светится бирюзой. Секретная — корабль над пирамидой, бирюзовое свечение по ободу.
- **Green Team Wins** — пати-викторина. Обычная: бирюзовый «мемфис» (треугольники, зигзаги), толстая тёмная обводка, орёл — зелёная галочка, решка — цифры «1 2 3» в кружках как на картах. Тёмная — ночная бирюза. Секретная — зелёная корона/кубок «победила зелёная команда», конфетти.
- **В общих чертах** — калька/синька. Обычная: бумага в клетку, графитовые линии; орёл — домик из трёх линий, решка — карандаш. Тёмная — синька: белые линии на синем. Секретная — «золотой чертёж»: синька с жёлтой рамкой-штампом и звёздочкой.

## Порядок и проверка
1. Сначала по одному листу на игру (обычная светлая) — показать владельцу; следующий облик — после ответа (решение «Обновление монет»: по одному спрайту на проверку). Потом остальные три облика каждой игры.
2. После одобрения подключить в `hub/fidget.gd`: TEXTURES (`<id>`, `<id>_dark`, `<id>_secret`, `<id>_dark_secret`) и сопоставление игры в GAME_COINS по образцу Things in Rings / Ready Set Bet.
3. Проверить: `godot --headless --audio-driver Dummy --path . res://tools/_fuzz/compile.tscn` без ошибок; снимок стола каждой игры в светлой и тёмной теме — монетка в гнезде TopBar, обе стороны читаются при 1280×720; секрет переключается пятью орлами.
4. Записи: `docs/PATCHNOTES.md` (В разработке), `hub/whats_new.md` — про секретные монеты только намёк, без инструкции; `REVIEW_QUEUE.md` — запись на ревью Claude.
