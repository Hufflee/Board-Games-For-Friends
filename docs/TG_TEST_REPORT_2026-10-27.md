# The Gang — проверка базовой версии · 27.10.2026

## Объём

Базовые правила,3–10 игроков (7–10 — расширение TTS), полностью2D. Локальные места для проверки; без полноценных ботов. Автоматический случайный выбор свободных фишек по таймеру. Коробка предоставлена владельцем. Дополнительные режимы и специальные карты в этот этап не входят. Работа над Айзеком не возобновлялась.

Реализация правил и авторский тест — Sol medium; отдельное ревью логики и сети — Sol low. UI/ассеты/хаб/первичная интеграция и фактические UI/ENet-прогоны — координатор Codex; исправления подтверждённых замечаний — medium с повтором low. Claude недоступен, его ревью не заявляется.

## Найденное и исправленное

- Полноэкранный MarginContainer перехватывал ввод верхней полосы, несмотря на z_index: исправлен только его mouse_filter, дочерние элементы активны.
- Новая вместимость пати10 делала достижимым отрицательный максимум set_bots для старой игры: ограничены добавочные места и проверяется фактическое число участников перед стартом.
- Статус вылетевшего игрока Gang ошибочно объявлялся обычным ботом: имя/роль сохраняются, сообщение описывает случайный выбор по таймеру.
- Отдельные ошибки подготовки тестов (слишком ранняя загрузка UI-класса до autoload, false в команде Python, диагностическое окно после аварии, ожидание перемещения курсора) исправлены в harness. Отрицательные журналы сохранены; они не приписываются новым игровым дефектам и не засчитываются успешными прогонами.

## Ограничения

Steam-приглашения/пакеты и10 одновременных удалённых клиентов не проверялись. Десять мест проверены локально и прямым Net-контрактом; реальный ENet — тремя процессами. Чат подключён через общую TopBar, отдельный новый сценарий чата в этом пакете не выполнялся. Полные партии через Steam/ENet не заявляются.

В хабе осталось прежнее предупреждение `SpatialMaterial ... specular` из `_furniture`; оно не связано с The Gang и в эту задачу не исправлялось. Проверка коробки завершилась штатно; первичный невалидный harness с ранней статической загрузкой GameBox отделён от финального результата.

Экспорт, коммит и релиз не выполнялись. Визуал и игровые сценарии можно проверить из хаба через новую коробку The Gang; локальный запуск создаёт3 места, кнопкой «+ Игрок» можно довести до10.
