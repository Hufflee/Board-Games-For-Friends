# Что улучшить в интерфейсе и как — план от 15.11.2026

Итог аудита [ui_audit.md](ui_audit.md) переложен на работы. Аудит отвечает на вопрос «что не так и где». Этот документ — «что сделать, в каком порядке, как именно и как проверить».
Принцип скилла `better-interface` «сначала дешёвое исправление»: удалить → использовать встроенное → переиспользовать своё → поправить значение → добавить новое. Поэтому почти везде предлагается одна общая функция в `hub/` и замена вызовов, а не правка каждой игры вручную.
Стили игр остаются своими. Меняются только значения внутри палитры и общие механизмы.

> **Решения владельца 15.11:** этап 3 (фокус и клавиатура) **отменён** — игра без мыши не нужна. Светлую тему не добавлять. Место кнопки «Общение» не ограничивать. Этап 6 — делать: отдельная галочка «Меньше движения» с пояснением при наведении (П12 задания). Рабочее задание с учётом этого — [TODO_codex_ui_2026-11-15.md](TODO_codex_ui_2026-11-15.md); где расходится с этим файлом — главнее задание.

## Этап 1. Читаемость: контраст в обеих темах

**Проблема.** В 18 играх и в TopBar текст ниже 4.5:1. Причины повторяются: (а) одна константа `MUTED` на обе темы (`br_style.gd:16`); (б) цвет команды затемняется и в тёмной теме (`wl_table.gd:193`, `ws_table.gd:296`); (в) акцентный цвет взят как цвет текста (`fc` `alien`, `st` `RED`, `ce` `brass`); (г) белый текст на средней заливке главной кнопки (`hc` `SAGE`, `mk` `ACCENT`, `fc` `ochre`, `tt` 18+); (д) токен, у которого в тёмной теме другой смысл (`rsb` `CREAM` = тёмная плашка, а используется как светлый текст).

**Как делать.**
1. **Одна функция выбора цвета текста** в `hub/` (например, `hub/ui_contrast.gd`, `class_name UIContrast`):
   ```gdscript
   ## Контраст двух цветов по WCAG (1..21). Альфу fg предварительно смешать с bg.
   static func ratio(fg: Color, bg: Color) -> float
   ## Из кандидатов вернуть первый с контрастом >= need, иначе самый контрастный.
   static func pick(bg: Color, candidates: Array[Color], need := 4.5) -> Color
   ```
   Применить там, где цвет текста считается «на глаз»: `cg_style.gd:35-40` (цвета автора), `hc_table.gd:404-408` (клетки), `wl_table.gd:256` (карточка), `wl_dial.gd:68` (цифры зон).
2. **В каждом `*_style.gd` — роли, а не константы.** Где тема есть, `muted()`, `team_ink(t)`, `danger_text()`, `accent_text()` возвращают значение для текущей темы. Конкретные значения (посчитаны) — в таблицах `ui_audit.md`. Короткий список:
   - brodilka: `muted()` → тёмная тема `INK.lightened(0.15)`; `QuietButton` hover — красная только рамка.
   - colt_express: значок «ВКЛ» — `ink` + рамка `brass`; LIGHT `muted` → `6b5236`.
   - first_contact: новый ключ `alien_text = 0b7a70` (светлая), `ochre` → `9a5f14`, `muted` → `65502f`.
   - green_team_wins: на бирюзовом фоне только `ink`; `muted` — только на панелях.
   - wavelength, word_slam: `team_ink(t)` (светлая `darkened(0.3)`, тёмная `lightened(0.2)`); слова карточки в тёмной теме — `ON_ACCENT`.
   - hues_and_cues (общий с WS и WL): `SAGE` светлой темы → `4a7a69`, `MUTED` → `63666e`.
   - ready_set_bet: VIP-текст → `CREAM_ART`; RichText-цвета из `RSBStyle.MONEY/RED.to_html()`; `MUTED` → `6b5842`.
   - stillion: `red_text()` для тёмной темы; занятые буквы — α 0.55.
   - gloom: подсказки `SILVER` вместо `MUTED`.
   - machi_koro: `ACCENT` → `1f7a81`; «Цена» в светлой `darkened(0.2)`.
   - four_souls: текст на главной кнопке — `PAPER`.
   - phantom_ink, custom, the_gang, the_mind: перестать хранить информацию в недоступных кнопках (S12), тогда `font_disabled_color` больше не красит основной текст.
   - khorom: `GOOD/BAD` в светлой темнее, плейсхолдер α 0.85.
   - tip_top 18+: текст главной кнопки `INK`.
3. **Порог.** Основной текст ≥ 4.5:1. Крупный (≥ 24 px, или ≥ 19 px жирный) ≥ 3:1. Рамки элементов управления ≥ 3:1. Недоступные кнопки — без требований, но не ниже 3:1, иначе их не видно вовсе.

**Как проверить.** Скрипт из этапа 8 (`tools/ui_contrast_check.gd`) — ноль пар ниже порога. Снимки `codex_games_shot` в светлой и тёмной теме по каждой изменённой игре.

## Этап 2. Обрезанный текст и склонения

**Проблема.** 25+ мест с `clip_text`/`OVERRUN_TRIM_ELLIPSIS` без способа прочесть полный текст. Хуже всего — обрезанные ответы игроков, по которым принимают решение (`ibs_app.gd:623`, `kh_notebook.gd:72`, `gtw_app.gd:560`, `st_table.gd:787`). Плюс «1 карт», «2 очков» в 10 местах.

**Как делать.**
1. Общая функция `hub/ui_text.gd`:
   ```gdscript
   ## Обрезанный текст: тултип с полным текстом появляется, только когда текст не влез.
   static func full_on_hover(c: Control) -> void   # Label или Button; следит за resized и сменой текста
   ## Русские формы: plural(1, "карта","карты","карт") → "1 карта"
   static func plural(n: int, one: String, few: String, many: String) -> String
   ```
   `plural` — перенести готовую логику из `gl_table.gd:1381` и `mg_blackjack_view.gd:165`, оба места переключить на общую.
2. **Ответы игроков — без обрезки.** Ответ выводить отдельной строкой с `AUTOWRAP_WORD_SMART` (максимум 2 строки), на кнопке — только глагол: «Засчитать ответ», «Отправить ответ». Это убирает целый класс проблем, а не прячет его за тултипом.
3. **Ники.** `full_on_hover` во всех местах из S4 (`ui_audit.md`, раздел 2). В TopBar — для `info`.
4. **Склонения.** Заменить все места из S10: `tm_table.gd:115,178`, `fs_table.gd:1285,1309`, `gl_table.gd:926`, `cg_table.gd:254`, `ce_app.gd:896`, `hc_table.gd:503`, `br_rules.gd:501`. Найти остальные: `grep -rnE '"[^"]*%d (карт|очков|монет|фишек|ходов|слов)'`.

**Как проверить.** Тест в `tests/` на `plural` (1, 2, 5, 11, 21, 112). Hot-seat-партия с ником из 24 символов в играх из S4 — наведение показывает полный ник.

## Этап 3. Фокус и клавиатура — ОТМЕНЁН (владелец 15.11: игра без мыши не нужна; оставлено для истории)

**Проблема.** В темах всех игр, кроме custom, фокус пустой или такой же, как обычное состояние. Плюс `FOCUS_NONE` на действиях игрока. Tab владелец отдал под меню (решение 31.10), поэтому переход фокуса по Tab на столе не работает, хотя Enter и Space по-прежнему срабатывают на кнопке в фокусе. Игрок не видит, что нажмёт.

**Как делать.**
1. Общая функция в `hub/` (`UIFocus.ring`):
   ```gdscript
   ## Рамка фокуса из стиля normal: без заливки, рамка 2 px цветом акцента игры, наружу на 2 px.
   static func ring(normal: StyleBox, color: Color, width := 2) -> StyleBox
   ```
   В `theme()` каждой игры заменить `StyleBoxEmpty.new()` на `UIFocus.ring(normal_box, ACCENT)`. Образец уже есть: `cg_style.gd:171-175`. Список файлов — S1 в аудите. Это одна строка на игру.
2. **Кольцо только при клавиатуре.** Чтобы рамка не появлялась после клика мышью (в Godot кнопка забирает фокус и при клике), в той же функции или в автозагрузке: при `InputEventMouseButton` снимать фокус с кнопки (`release_focus()` после `pressed`), при стрелках и Enter — не трогать. Это аналог `:focus-visible` из веба.
3. **Навигация без Tab.** На столе Tab открывает меню, поэтому ходить стрелками: Godot сам ищет соседей по `ui_left/right/up/down`, если `focus_mode = FOCUS_ALL`. Убрать `FOCUS_NONE` у действий игрока (список S2). В меню TopBar при открытии ставить фокус на первую кнопку (`top_bar.gd:set_menu_open`).
4. **Esc закрывает окна.** Gloom (`gl_table.gd:906`), гримуар и справочник Башни (`bc_grimoire.gd`, `bc_handbook.gd`), превью Кольта — `_unhandled_input` с `ui_cancel` → закрыть верхнее окно и `set_input_as_handled()`. `TopBar._has_modal` уже не открывает меню, пока виден модальный слой: это сохранится.
5. **Перетаскивание — с запасным путём (S3).** The Gang: клик по фишке центра — взять, клик по своей — вернуть. RSB: выбор жетона кликом (уже есть `_selected_tok`) → клик по клетке. Шкаф и стикеры хаба можно оставить: это декор, не игра.
6. **Кнопки-иконки с именем.** `fs_action_feed.gd:82` — `tooltip_text` по типу записи. Остальные кнопки-иконки уже с тултипами (проверено в хабе и TopBar).

**Как проверить.** В каждой игре: стрелками дойти до главной кнопки — рамка видна в обеих темах (контраст рамки ≥ 3:1 к фону); Enter срабатывает; Esc закрывает окно; клик мышью рамку не оставляет. Можно добавить сценарий в `tools/_shot`: послать `ui_right` ×3 и снять кадр.

## Этап 4. Подсказки на виду, карты — через превью

**Проблема.** Почему кнопка недоступна, что означает комната, какое правило у «Оспорить» — всё это только в тултипах (S11). Текст карт местами тоже в тултипах (S13) — это нарушает правило 9 из `CLAUDE.md`.

**Как делать.**
1. **Шаблон «главная кнопка + строка причины».** У большинства столов главная кнопка внизу. Над ней строка размера `CAP`, цвет `muted()`: «Положите на планшет все ответы», «Нужно минимум 3 игрока», «Сначала проведите линию». Если кнопка доступна, строка пустая (место под неё держать, чтобы ничего не прыгало). Хорошо бы вынести в общий помощник, например `UIHint.under(button, text)`.
   Места: `tt_table.gd:574`, `ibs_app.gd:581`, `tr_table.gd:240`, `tm_table.gd:244`, `tg_app.gd:156`, `nh_table.gd:478`, `dw_table.gd:778`, `st_table.gd:253`, `perudo_table.gd:544,931`.
2. **Карты.** Заменить тултипы на крупный просмотр: `card_view.gd:67` (king_of_12), `nh_card.gd:45` + `nh_table.gd:178`, `rsb_table.gd:370` (VIP), `br_table.gd:1025` (Лавка), `gl_table.gd:355-371` (персонажи — в тултипе оставить имя). Образец — `br_table.gd: _hoverable`, `gl_table.gd: _show_preview`, `hub/card_magnifier.gd`.
3. **Смысл не только цветом.** First Contact — номер или глиф фракции в кружке (`fc_app.gd:115-122`). Green Team Wins — «✓»/«·» или слово команды в чипе итогов. Things in Rings — текст «Верно»/«Неверно» рядом со вспышкой. Word Slam — полоска таймера тоже `CLAY` + ⚠. Покер — «✓» у выбранного пред-хода. Башня — значок команды у роли (`bc_table.gd:407`).
4. **Не прятать информацию в недоступных кнопках (S12).** Phantom Ink (`pi_table.gd:232`), custom (`cg_table.gd:260,405`), The Gang (`tg_table.gd:133`), Unspoken (`tm_table.gd:122`): строки и места, на которые нельзя нажать, — `PanelContainer` + `Label` с тем же видом. Где нажатие нужно только в hot-seat — кнопка с `mouse_filter = IGNORE`, без `disabled`.
5. **Phantom Ink: выбор ≠ главное действие.** Выбранные вопросы, голоса и слово духа — `SelectedButton` (определён в `pi_style.gd:63`, нигде не используется), `PrimaryButton` — только «Передать два вопроса».

**Как проверить.** По каждой игре: недоступная главная кнопка всегда с видимой причиной. Наведение на любую карту даёт крупный просмотр, не тултип (grep `tooltip_text.*card_text|vip_text|gift_name` пуст). Снимок в ч/б (Image → `convert(FORMAT_L8)`): команда или фракция различимы без цвета.

## Этап 5. Типографика

**Как делать.**
1. **Нижняя граница 12 px (подписи 13).** TopBar: название 11 → 13 без альфы, часы 12 → 13 (`top_bar.gd:95,116`). Карты и плитки: `card_view.gd:62` (11), `nh_card.gd:36-37` (11), `fc_app.gd:104-125` (сжатие до 10 → минимум 12 и перенос на 2 строки), `tt_answer_face.gd:45-47`. Прочие 12 px — в `CAP` игры.
2. **≤ 3 размеров на экран.** Убрать ad hoc-размеры в `gtw_app.gd`, `fc_app.gd`, `ibs_app.gd`, `pk_table.gd`, `tg_table.gd`, `bc_grimoire.gd`, `hub.gd:356-430`. Если нужен четвёртый размер (крупное «слово-ответ»), объявить его константой в `*_style.gd` и записать роль.
3. **Моноширинные цифры.** В `font()` каждой игры — вариант `font("num")`: тот же `FontVariation` с `opentype_features = {"tnum": 1}`. Нужно проверить, есть ли `tnum` у шрифта: у Manrope, Nunito, Exo 2, Rubik есть; у Oswald и Alegreya Sans проверить. Если нет — `custom_minimum_size.x` по ширине «00:00», как уже сделано в `dw_table.gd:341`. Места — S14.
4. **Мелочи текста.** `wl_table.gd:145`: `capitalize()` → первая буква. `...` → `…` (`comms_panel.gd:14`, `chat_panel.gd:8`, «думает...» в покере). «OK» → «Закрыть» (`pi_table.gd:445`). «Да, ловушка!» → «Засчитать ловушку» (`dw_table.gd:771`). «Нарушение» → «Отметить нарушение» (`dw_table.gd:778`). «Отключить действия <имя>» → «Повторять действия <имя>» (`hub.gd:398`). Восклицательные знаки на обычных кнопках Стиллиона.
5. **Phantom Ink: выравнивание пробелами** (`pi_table.gd:168,211`) → отдельная колонка `Label` с фиксированной шириной под номер.

**Как проверить.** grep `font_size", (1[01]|[0-9])\)` пуст. Снимки: таймер и счёт не сдвигают соседние элементы при смене цифр.

## Этап 6. Настройка «Меньше движения»

**Проблема.** Блик на главных кнопках (`ui_accent_fx.gd`, на всех кнопках `primary`) крутится постоянно. Плёнка Стиллиона мерцает. Пульсации хода (`set_loops()`) не выключаются. Есть только «Двигающийся фон», и его слушают 7 файлов.

**Как делать.**
1. В `Prefs` — `reduce_motion := false` (или переименовать `parallax` в более общий смысл, сохранив ключ в конфиге). В настройках: «Меньше движения — без бликов, мерцания и качания; фон не следует за мышью».
2. Проверка в `ui_accent_fx.gd` (`sheen()` не создаёт блик), `st_style.gd:236-246` (`FilmFX` без мерцания), в твинах пульса хода (заменить пульс на статичную подсветку той же заливкой), в `cursor_parallax.gd` (уже есть).
3. Анимации, которые несут информацию (полёт кубика, перемещение фишки, раздача карт), оставить, но короче: при `reduce_motion` — длительность ×0.5 и без «прыжков». Результат должен оставаться виден статично (цифра на кубике, фишка на клетке) — это уже так.

**Как проверить.** С включённой настройкой 30 с на столе каждой игры: ничего не движется само, кроме таймера хода.

## Этап 7. Общие элементы: TopBar и «Общение»

1. **Клавиша меню (Tab)** (`hub/escape_key.gd:8,29,35`): ink в тёмных играх из `text` стола с α ≥ 0.75, рамка и подложка α 0.25. Это единственный признак меню, где лежат «Правила» и «Выйти».
2. **Кнопки меню доступны с клавиатуры** (`top_bar.gd:261` — убрать `FOCUS_NONE`, см. этап 3).
3. **Ряд меню не сжимать ниже 0.85** (`top_bar.gd:349-352`): при нехватке места убирать «Панель хоста» и «Зритель» под «Ещё ▾».
4. **Свёрнутое «Общение»** (`float_panel.gd`): текст свёрнутой кнопки — `ink` палитры, не приглушённый; в `_clamped` отступ ≥ 8 px от краёв; не ставить кнопку на игровое поле — пусть игра отдаёт прямоугольник поля (как `coin_at` у TopBar), и `_clamped` его обходит.
5. **Хаб.** «Выход» (`hub.gd:152`) — `QuietButton` + `LeaveGuard.hold` (сейчас закрывает игру с одного клика и выглядит как остальные). Верхний ряд: громкими оставить «Общение» и «Настройки», остальное тише. Подложка под подсказкой «ЛКМ — открыть игру…» (`neon_room.gd:23`). Подпись над полем кода пати и понятная ошибка при нечисловом коде (`hub.gd:367-373`). Шкала размеров в панели пати.

## Этап 8. Защита от повторения

Три недорогие проверки, по образцу `tools/_fuzz/compile.tscn`:

2. **`tools/ui_lint.gd`** (headless или Python): grep по `games/*/ui` и `hub/` — `StyleBoxEmpty` на `"focus"`, `FOCUS_NONE` вне списка разрешённых, `font_size` < 12, `clip_text = true` без `full_on_hover` в той же функции, `"%d карт"`-подобные строки без `plural`, `tooltip_text` с `card_text`. Печатает файл:строку.
3. **Снимки обеих тем по всем играм** — уже работают (`tools/_shot/codex_games_shot.tscn`). Скрипт пакетного прогона из этой проверки стоит положить в `tools/_shot/all_games.sh`, чтобы после правок было с чем сравнить.

Плюс в чек-лист внешнего вида в `CLAUDE.md` (после согласования с владельцем) — 4 строки:
- текст ≥ 12 px, контраст ≥ 4.5:1 в обеих темах (`ui_contrast_check`);
- обрезанный текст — с `UIText.full_on_hover`, ответы игроков не обрезать;
- причина недоступной главной кнопки — видимой строкой, не только тултипом.
