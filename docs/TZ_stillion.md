# ТЗ: «Стиллион»

Своя игра (без настольного прототипа): ПвП-викторина на скорость печати с механикой «горячей картошки».
Код — `games/stillion/` (префикс `st_`), тесты — `tests/test_stillion.gd`.

## Суть
- 2–8 игроков стоят по кругу, в центре — чёрная мультяшная пушка с глазами.
- Пушка наводится на игрока и надувается, горит фитиль. Пока не догорел — игрок печатает ответ на вопрос сверху (Enter).
- Верный ответ: пушка сдувается и поворачивается к следующему **по часовой стрелке**; ему — тот же вопрос, названные ответы больше не принимаются.
- Не успел — выстрел, −1 жизнь (их 3). Без жизней — выбывает. Последний выживший побеждает.
- Неверный ответ можно исправлять, пока горит фитиль. Опечатки в 1–2 буквы исправляются автоматически.

## Редкость и шкала
- Ответы делятся на «Общеизвестно / Школьник / Умник / Эрудит» — 1 / 2 / 3 / 4 очка шкалы под игроком.
- Шкала по умолчанию 20 очков (настройка комнаты `st_meter`): заполнилась — +1 жизнь (не больше максимума), шкала с нуля.

## Темп
- Фитиль: на каждом новом вопросе 12 с, после каждого верного ответа на этот вопрос короче на 1 с (минимум 5 с).
- Смена вопроса: пауза 2,2 с (фаза `new_q`) — на столе «Новый вопрос!», сам вопрос и таймер скрыты (хост не присылает текст), затем наведение и фитиль.
- Вопрос меняется при смене цели, если на нём прошло 25 с или двое потеряли жизнь (или кончились известные ответы).

## Вопросы
- `logic/st_questions.gd`: 10 категорий — Русский язык, География, Еда, Человек, Природа, Кино, Английский язык, Спорт, Игры, Литература — по 12 вопросов (120).
- Вопрос — на узкий, конечный набор ответов (не «назовите насекомое», а «назовите дикую кошку»): общеизвестных ответов мало, чтобы по кругу быстро приходилось думать.
- Вопросы не повторяются за сессию лобби: колода общая для всех партий подряд (`Net._st_deck`), сбрасывается при выходе к выбору игры или из лобби; кончилась — перемешивается заново.
- У вопроса — известные ответы по редкости (`c:/s:/u:/e:`), синонимы через `|`. Нужны для мгновенной проверки без сети и для ботов.

## Проверка ответа
1. `STJudge.lookup`: нормализация (регистр, ё/е, знаки), поиск по списку с допуском опечаток (Левенштейн: до 3 букв — точно, 4–6 — 1, длиннее — 2).
2. Нет в списке → если у ведущего подключён **Jev** (Typesafe AI, System One): `POST https://api.typesafe.ai/v1/systemone`, вопросы `correct` (noul: верно ли, опечатки прощать) и `rarity` (choice: common/school/smart/erudite). Пока проверяем — фитиль стоит; 8 с без ответа — не засчитано. Засчитано при «верно» ≥ 0,4; редкость Jev поднимается на ступень (common → школьник, school → умник, smart/erudite → эрудит) — калибровка по прогону всех ответов, см. `docs/stillion_jev_check.md`. Засчитанный jev ответ не из списка хост дописывает в `user://stillion_new_answers.jsonl`; сводка для проверки — `python -I tools/st_new_answers.py`, верные ответы переносятся в списки.
3. Без Jev засчитываются только ответы из списка.
- Ключ API — только локально у ведущего: `user://stillion.cfg` (поле в лобби) или переменная `TYPESAFE_API_KEY`. В репозиторий и экспорт не попадает.

## Сеть
- Всё считает хост (`STRules` в `Net.stillion`), клиенты шлют `st_answer {text}`; на одном компьютере — `{as: цель}`.
- В офлайне — местные игроки по очереди за клавиатурой; переключатель «Добавленные — боты» делает добавленные места ботами (`st_bots`).
- Отключившегося игрока заменяет бот.

## Вид
- Стиль мультфильмов 30-х (Cuphead / rubber hose): кремовая бумага, толстый чёрный контур, тень со сдвигом, горчичный и красный; поверх — плёнка (зерно, виньетка, мерцание, редкие царапины). Светлая и тёмная тема.
- Пушка — `ui/st_cannon.gd`, рисуется кодом: надувание с «бульканьем», краснеет перед выстрелом, злые глаза с «пирожковыми» зрачками смотрят на цель, моргают; фитиль с искрами укорачивается; выстрел — отдача, вспышка, дым.
- Персонажи — фишки «Большой бродилки». Шрифты — Underdog (заголовки), Nunito (текст).
- Фоны `art/bg_stage.jpg`, `art/bg_menu.jpg`, обложка `hub/covers/stillion_*` — ComfyUI (без них — процедурные «лучи»).
- Звуки синтезированы: выстрел, фитиль, сдувание, «верно», «мимо».
