# ТЗ: «Покер» (poker)

Техасский холдем без лимита на 2–8 игроков. Классическая общественная игра; два режима — «Классика» и «Спортивный» (своя идея владельца).
Префикс файлов — `pk_`. Карты — из The Gang (`games/the_gang/art/cards`, оценка рук — `TGPoker`).

## Общее
- Все начинают со **100 BB**. Блайнды фиксированные **1/2** → стек 200 фишек.
- Раздача: дилер-кнопка по кругу, малый и большой блайнд, по 2 карты, торговля префлоп → флоп (3) → тёрн → ривер → вскрытие.
  Вдвоём (heads-up) кнопка — малый блайнд и ходит первой префлоп.
- Ходы: «Пас», «Чек» / «Колл N», «Рейз до N» (минимум — текущая ставка + последнее повышение), «Ва-банк».
  Неполный ва-банк не открывает торговлю заново для тех, кто уже ходил (они могут только уравнять или сбросить).
- Банк и побочные банки — по вкладам; делёж поровну, лишняя фишка — первому победителю слева от кнопки.
- Вскрытие: показываются руки всех, кто дошёл; у каждого — название комбинации. Все пасанули — банк без вскрытия.
- Время на ход 30 с: истекло — чек, если можно, иначе пас (так же за отключившегося).

## Режим «Классика»
- Раздачи без ограничения. Проиграл стек — кнопка «Сесть заново» (снова 100 BB, счётчик докупок). Боты садятся сами.
- Хост может «Завершить игру»: побеждает тот, у кого больше всего итог (стек − 200 × (1 + докупки)).

## Режим «Спортивный»
- Сессия = **14 раздач**. Вылетевший сидит до конца сессии. Сессия кончается и раньше, если фишки остались у одного.
- Места по итогу сессии: по стеку; вылетевшие — ниже всех, по порядку вылета (первый вылетевший — последний;
  вылетели в одной раздаче — у кого было больше фишек перед ней, тот выше). Равный стек — общее место.
- Очки за место при N игроках: 1-е — N, 2-е — N−1, …, предпоследнее — 2, последнее — **0** (4 игрока: 4/3/2/0).
- После сессии стеки снова 100 BB. **Победа** — первым набрать **2N + 1** очков (4 игрока — 9). Набрали одновременно —
  побеждает больший счёт, равный — общая победа.

## Офлайн и сеть
- Офлайн — с ботами (у каждого скрытые карты, горячие места не подходят). Боты: префлоп — сила стартовой руки,
  дальше — оценка шансов перебором (Монте-Карло) и шансы банка; иногда блефуют.
- Всё считает хост; клиенту уходят только свои карты (чужие — на вскрытии). Настройки `pk_mode` (classic/sport).

## Интерфейс (стиль — неоновый Лас-Вегас, богаче «Хором!»)
- Тёмно-фиолетовая комната, овальный стол с сукном и неоновой каймой (розовый + голубой), свечение, огни.
  Заголовки — Russo One, текст — Exo 2. Главный цвет — неоновый розовый, акцент главного действия — золото.
- Места по овалу: имя, стек, последнее действие, 2 карты (свои — крупно снизу). Кнопка дилера, метки SB/BB.
  Чей ход — подсветка места и полоска времени.
- **Фишки — только визуал**: перед местом лежит спрайт по размеру ставки — 1 фишка / столбик / два / россыпь / **гора**
  (`games/poker/art/chips/pile_1..5.png`, рисуются `tools/chips_poker.py`). В центре — банк тем же спрайтом.
- Панель ставки: поле ввода, ползунок (от минимального рейза до ва-банка), кнопки **2× / 3× / 4×** от текущей ставки
  (нет ставки — от большого блайнда), «Пас», «Чек/Колл», главная — «Рейз до N» / «Ставка N».
- Карты — общий просмотр при наведении. Слева/справа — журнал раздачи; в спортивном — таблица очков и номер раздачи «7/14».
- TopBar: «Покер», раздача/сессия; Правила, Настройки, тема, Журнал, «Выйти».
