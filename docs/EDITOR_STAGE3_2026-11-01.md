# Редактор — пакеты и библиотека, 01.11.2026

Добавлены CGPackage, CGLibrary, CGTransfer. Пакет содержит только game.json, изображения/шрифты с SHA-256 в имени и четыре обложки/миниатюру. История и черновики не передаются. ZIP проверяется до ZIPReader: каталог, локальные заголовки, допустимые имена, ссылки/шифрование/методы сжатия, до 1000 файлов, до 64 МБ сжатых и распакованных данных, JSON до1 МБ, шрифт до10 МБ. Размер картинки читается из PNG/JPEG/WebP до декодирования; предел2048 px. Ассеты сверяются с хэшами, определение — с CGDef. Не используется ResourceLoader для пользовательских файлов, не выполняется пользовательский код.

Исходники автора живут в user://custom_games/UUID; сохранение через временный файл/резервную предыдущую версию, 10 снимков истории. Номер версии растёт при сохранении. Ошибочный основной JSON можно прочитать из .bak. Собранный пакет имеет стабильный хэш при неизменных данных. Полученная игра остаётся только в user://custom_cache; в шкаф и редактирование клиента не добавляется. Кэш очищается по дате использования до1 ГБ, активный хэш сохраняется.

Хост объявляет UUID/hash/size/title и отправляет надёжные части по48 КБ по очереди клиентам с промежутком. До подтверждения готовности всех участников старт закрыт. Получатель проверяет хэш/ZIP/файлы/схему и только затем подтверждает. Частичный буфер сохраняется при разрыве соединения в текущем процессе; после возврата запрашивается следующее смещение. После полного закрытия приложения частичная загрузка начинается заново (докачка между перезапусками пока не сделана).

HubGames.LIST сохранён const, all() объединяет встроенные и авторские игры. Хаб/окошки/статистика используют all(), by_id разрешает маршрут игры друга без добавления коробки клиенту. В шкаф добавляются настоящие GameBox, общий ShelfConfig размещает их в свободных ячейках. Обложки читаются Image из авторской папки, габариты берутся из четырёх шаблонов, есть метка «Своя игра». Пустая коробка пока имеет текстовую заглушку, её текст умещается в грань. Художественный редактор коробки — этап7.
