# Rulebook — правила из повторённых ошибок

Если нейросеть (Claude или Codex) совершила **одну и ту же ошибку второй раз** — сюда добавляется правило.
Формат: **ошибка** → как делать правильно → как проверить. Кто и когда — в конце строки.

- **Скриншоты Godot в папку Temp/scratchpad иногда не сохраняются** → сохранять в `build/shots` (`OUT=…/build/shots`), потом обрабатывать оттуда. Проверка: файл `build/shots/*.png` появился. (Claude, 2026-10-24)
- **`:=` от значения Variant (элемент Array/Dictionary) — ошибка компиляции «Cannot infer the type»** → явный тип: `var x: int = arr[i]`, у переменной цикла — тоже. Проверка: `tools/_fuzz/compile.tscn` → `SCRIPTS N` без ошибок. (Claude, 2026-10-24)

- **Запись патчноута пропускается после переименования «В разработке» при релизе** → перед правкой читать текущие заголовки; если раздела нет, создать новый «В разработке» перед первой выпущенной версией. Проверка: новая запись находится именно в новом разделе, старый релиз сохранён. (Codex, 2026-10-24)
- **Плотный «минифицированный» GDScript: несколько операторов через `;`, без пробелов вокруг `=`/`,`, без комментариев** (hub/private_hand.gd, затем hub/player_stats.gd и hub/match_metrics.gd) → писать как остальной проект: один оператор в строке, пробелы вокруг операторов и после запятых, типизация, док-комментарий `##` в начале файла и у неочевидных функций. Проверка: перед сдачей просмотреть новый файл — нет ли `;` и строк длиннее ~140 символов с несколькими действиями. (Codex, 2026-10-24)

- **gdformat переносит многострочный lambda-аргумент вложенного вызова с недопустимым для Godot отступом** → выносить такой callback в именованный метод; совпадение AST gdtoolkit не заменяет компиляцию настоящим Godot. Проверять журнал compile, а не только код выхода (сцена compile может завершиться с 0 при ошибках отдельных скриптов). (Codex, 2026-10-25)
